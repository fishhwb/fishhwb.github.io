What this site does

FISH HWB is a static GitHub Pages site. It does not use site analytics, advertising cookies or a server-side account system. The public pages are here to provide information, media links and OAuth return pages for associated software.

CubeZ

CubeZ is designed as a local-first desktop application. Projects, settings and platform credentials are kept on the operator's device. When an operator deliberately connects a third-party platform, CubeZ communicates with that platform as needed to complete the requested action.

TikTok

The TikTok callback at /auth/tiktok/ reads the browser URL so it can display the one-time authorisation code. The static page does not upload that code to FISH HWB infrastructure. The operator returns the code to CubeZ, which completes its own token exchange.

Third-party platforms

Twitch, Spotify, YouTube, TikTok and other linked services operate under their own policies. This site does not control data those services collect when you use them.

Contact

For project questions, use the relevant project repository or its published contact route.
